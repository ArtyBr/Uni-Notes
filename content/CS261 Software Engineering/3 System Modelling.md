System design seeks to **remove ambiguities** from the requirements analysis

UML developed in the 1990s as general purpose **modelling language**

Perspectives for system modelling
- **External**
	- Model the context of the system
- **Interaction**
	- Model the interactions between the system and its environment, or between components of a system
- **Structural**
	- Model the organisation of a system or the structure of the data being processed
- **Behavioral**
	- Model dynamic behaviour of the system
### UML
UML can be used to describe systems in 2 ways:
- Static/Structural view
- Dynamic/Behavioral view
