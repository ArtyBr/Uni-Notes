# Neuron
- Our brain consists of billions of neurons which are connected to each other via **synapses**
- **Neurons** (also called **nerve cells**) are the fundamental building unit of the brain

# Neural Network
A neural network mimics the association of neurons, which is the most important mechanism in the brain

As opposed to traditional ML techniques such as SVMs, where you need to manually specify the kernel functions to retrieve desired attributes, Neural Networks learn the best kernels themselves, reducing the need for human input in this.
