- Then you could apply the reverse transform to reconstruct it back

Next, we can get a **variational auto-encoder**
- Most influential auto-encoder

![[Pasted image 20260310103512.png]]

The idea is that you re-define the $z$, the hidden space
- THrough the encoding you project the data into a Gaussian distribution
	- (before, it was projected just into a hidden space)
- Now, using a Gaussian distribution we can generate an infinite number of data points
- Generative function!

Using this they were able to generate human faces!

However, when trying to do this for ImageNet, with many different classes, the results are blurry and don't make much sense

**Generative Adversarial Model** (GAN)

![[Pasted image 20260310103822.png]]

When using VAE, we create a face but we don't check the quality of the output.
- However a **GAN** uses a discriminator to try to **tell the difference** of which image is fake or real
- It keeps teaching itself using this until it can trick the discriminator

![[Pasted image 20260310103926.png]]

For example, with this horse, it generates a zebra, and then from the zebra it tries to generate back
- The discriminator tries to tell if the final image is real or fake
- It keeps going until it can get the translation to be realistic

Next, we want to do this for **higher image resolutions**
- ProGAN starts out generating very low resolution images
- When training **stabilises** a new layer is added and the **resolution is doubled**
- This continuous until the output reaches the **desired resolution**
- By progressively growing the networks in this fashion, high-level structure is learned first, and training is stabilised

Next, they developed StyleGAN, based on ProGAN
- Works similar to ProGAN but you can also add prompts or styles to change the image by

There are certain datasets for helping with deepfake detection
However, there is a **generalisation issue** for deepfake detectors:

If a network is trained on a **specific architecture**, its performance **degrades** significantly when used to detect images generated by **another architecture**
